# 🤖 Botluyo - Topluyo Bot Geliştirici

Topluyo platformu için blok tabanlı bot geliştirme aracı.

## Özellikler
- 🎨 Sürükle-Bırak Blok Editörü
- 💻 Gerçek Zamanlı Kod Önizleme
- 📱 Mobil/Tablet/PC Uyumlu
- 💾 Proje Dosyalarını İndirme
- 🔑 Token ile Test

## Kullanım
index.html dosyasını tarayıcıda açın ve blokları sürükleyerek botunuzu oluşturun.
